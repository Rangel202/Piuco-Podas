# Piuco Podas

Site da Piuco Podas, empresa de serviços profissionais de poda de árvores, com foco em gerar pedidos de orçamento pelo WhatsApp.

🔗 **Site no ar:** https://rangel202.github.io/Piuco-Podas/

## Sobre o projeto

Projeto feito para cliente. É uma página única e responsiva, com SEO básico (título e descrição otimizados) e animações de entrada conforme a rolagem.

### Seções

- **Início:** apresentação e chamada para orçamento
- **Quem somos:** história e proposta da empresa
- **Serviços:** poda preventiva, remoção controlada e cuidados ambientais
- **Mostrando:** fotos de trabalhos realizados
- **Vantagens:** diferenciais do atendimento
- **Clientes:** depoimentos
- **Contato:** botão direto para o WhatsApp

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Hospedagem no GitHub Pages

## Como rodar localmente

É um site estático. Basta clonar o repositório e abrir o `index.html` no navegador:

```bash
git clone https://github.com/Rangel202/Piuco-Podas.git
```

## Estrutura

```
index.html   conteúdo da página
css/         estilos e responsividade
js/          interações e animações
images/      fotos usadas no site
```
